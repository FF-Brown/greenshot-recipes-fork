# Region with Drop Shadow in Editor

Select a screen region, apply a drop shadow, and open the result in the Greenshot editor for further edits.

## Use it

- Tray menu: **Region with Drop Shadow in Editor**
- Hotkey: Ctrl + Shift + PrintScreen; change it in the recipe settings

## Options

| Option | Default |
|---|---|
| Hotkey | Ctrl + Shift + PrintScreen |

## Allows

Opens the captured and shadowed image in the Greenshot editor. It does not save or send the image elsewhere.
